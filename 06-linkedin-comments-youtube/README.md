# LinkedIn Comments + YouTube Automation

An n8n workflow for processing content from LinkedIn and YouTube and using AI to assist with comment generation, content analysis, or engagement workflows.

## Features

* Content processing
* AI-assisted comment generation
* YouTube content analysis
* LinkedIn content processing
* Custom prompts
* Automated workflow execution

## Workflow Overview

```text
Content Source
      ↓
Collect Content
      ↓
Extract / Clean Text
      ↓
AI Analysis
      ↓
Generate Comment / Output
      ↓
Review or Publish
```

## Use Cases

* Social media engagement
* Content research
* Comment suggestions
* Audience research
* Content repurposing
* Creator workflows

## Requirements

* n8n
* Required platform/data access
* AI provider
* Optional YouTube/LinkedIn integrations
