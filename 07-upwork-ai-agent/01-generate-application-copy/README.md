# Generate Application Copy

An AI-powered n8n workflow for generating customized application or proposal copy from a job/project description and applicant information.

## Features

* Job description analysis
* AI-generated application copy
* Applicant profile integration
* Customizable prompts
* Structured output

## Workflow

```text
Job Description
      ↓
Applicant Information
      ↓
AI Analysis
      ↓
Generate Application
      ↓
Final Copy
```

## Use Cases

* Freelance applications
* Job applications
* Proposal generation
* Client outreach
* Project applications

## Requirements

* n8n
* AI provider
* Job/project description
* Applicant profile
