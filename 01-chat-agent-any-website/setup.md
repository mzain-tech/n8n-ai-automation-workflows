# Setup Guide — Chat Agent for Any Website

## 1. Requirements

Before importing the workflow, make sure you have:

* A running n8n instance
* An AI provider/API
* Access to your website
* Required API credentials

## 2. Import the Workflow

1. Open n8n.
2. Go to **Workflows**.
3. Select **Import from File**.
4. Select `workflow.json`.
5. Open the imported workflow.

## 3. Configure AI Credentials

Open the AI-related node and select or create the required credential.

Never place API keys directly inside frontend code.

## 4. Configure the AI Agent

Update the system instructions according to your business.

Example:

```text
You are a helpful customer support assistant.

Answer questions using the available business information.
Keep responses concise and professional.
If you do not know an answer, clearly say that you do not have enough information.
```

## 5. Configure Memory

If conversation memory is enabled, configure the session identifier so different visitors do not share the same conversation history.

A common session identifier is:

```text
visitor_id
```

or:

```text
conversation_id
```

## 6. Configure the Webhook

Copy the webhook URL generated by n8n.

Your website should send the visitor's message to the webhook.

Example request structure:

```json
{
  "message": "What services do you provide?",
  "session_id": "visitor-001"
}
```

## 7. Test the Workflow

Send a test request from your website or an API testing tool.

Verify that:

* The webhook receives the request.
* The AI Agent receives the message.
* Memory works correctly.
* A response is returned.

## 8. Activate

After successful testing, activate the workflow and connect your production website.

## Troubleshooting

### No response

Check the webhook and AI node execution logs.

### AI authentication error

Verify the configured API credential.

### Conversations are mixed

Check that each visitor receives a unique session ID.

### Website cannot access the webhook

Check CORS, webhook configuration, HTTPS, and your n8n deployment settings.
