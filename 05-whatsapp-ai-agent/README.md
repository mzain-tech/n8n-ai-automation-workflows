# WhatsApp AI Agent

An AI-powered WhatsApp automation workflow built with n8n for handling incoming customer messages and generating automated responses.

## Features

* Automated WhatsApp responses
* AI-powered conversations
* Customer message processing
* Conversation context
* Custom business instructions
* Automated customer support
* Lead qualification

## Workflow Overview

```text
WhatsApp Message
       ↓
Webhook
       ↓
Process Message
       ↓
AI Agent
       ↓
Conversation Context
       ↓
Generate Response
       ↓
Send WhatsApp Reply
```

## Use Cases

* Customer support
* Lead qualification
* Product inquiries
* Appointment requests
* FAQ automation
* Sales assistants

## Requirements

* n8n
* WhatsApp Business-compatible API/provider
* AI provider
* Required credentials
* Public HTTPS webhook endpoint
